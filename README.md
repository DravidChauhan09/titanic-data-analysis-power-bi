# 🚢 Titanic Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project analyzes the Titanic passenger dataset to understand the factors that influenced passenger survival.

The data was analyzed and cleaned using Python and Pandas in Jupyter Notebook. The analysis was then presented through an interactive Power BI dashboard.

The project demonstrates the complete data analysis workflow from data cleaning and exploration to visualization and dashboard creation.

---

## 🎯 Project Objectives

- Analyze overall passenger survival.
- Compare survival rates between male and female passengers.
- Analyze survival based on passenger class.
- Identify the port with the highest survival percentage.
- Analyze the average fare paid by survivors.
- Understand passenger demographics and survival patterns.
- Create an interactive Power BI dashboard.

## 🧹 Data Cleaning

The Titanic dataset was cleaned and prepared before analysis.

Main steps included:

- Checking dataset structure.
- Checking missing values.
- Checking data types.
- Handling missing values in the `Age` column.
- Filling missing Age values using the median.
- Checking duplicate records.
- Preparing the dataset for analysis.

## 📊 Data Analysis

The following analysis was performed:

### 👥 Gender Analysis

Compared survival rates between male and female passengers.

### 🎫 Passenger Class Analysis

Analyzed survival rates across:

- 1st Class
- 2nd Class
- 3rd Class

### ⚓ Embarked Port Analysis

Compared survival percentages based on passenger embarkation ports.

### 💰 Fare Analysis

Calculated the average fare paid by passengers who survived.

### 👨‍👩‍👧 Passenger Analysis

Explored passenger demographics and their relationship with survival.

## 📈 Power BI Dashboard
